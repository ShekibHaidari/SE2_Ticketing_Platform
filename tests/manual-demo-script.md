# Persian Cinema Customer Demo Script

## هدف

نمایش جریان کامل مشتری در سامانه فروش بلیت سینما با رابط فارسی، انتخاب چند صندلی، قفل رزرو، پرداخت آزمایشی و مشاهده بلیت.

## مراحل اجرای دمو

1. استک را اجرا کنید:
   `cd infra/docker && cp .env.example .env && docker compose up --build`
2. مرورگر را باز کنید:
   `http://localhost:8080`
3. به عنوان خریدار وارد شوید:
   `customer@example.com / password123`
4. در صفحه فیلم‌ها با جستجو، شهر، سینما، ژانر یا تاریخ فیلتر اعمال کنید.
5. یکی از فیلم‌ها را با `مشاهده سانس‌ها` باز کنید.
6. در بخش جزئیات فیلم، یکی از سانس‌ها را با `انتخاب صندلی` انتخاب کنید.
7. روی `نمایش نقشه صندلی` کلیک کنید.
8. یک یا چند صندلی آزاد را انتخاب کنید.
9. بررسی کنید که خلاصه صندلی‌ها، تعداد و مبلغ کل نمایش داده می‌شود.
10. روی `قفل صندلی‌ها و ادامه پرداخت` کلیک کنید.
11. شمارش معکوس رزرو را ببینید و سپس `ادامه پرداخت` را بزنید.
12. برای سناریوی موفق، روی `پرداخت موفق آزمایشی` کلیک کنید.
13. بخش `بلیت نهایی` باید کد بلیت، وضعیت، فیلم، سینما، سالن، صندلی و QR را نمایش دهد.
14. با `مشاهده بلیت‌های من` لیست بلیت‌ها را باز کنید.
15. برای سناریوی ناموفق، در یک بار دیگر رزرو را انجام دهید و `پرداخت ناموفق آزمایشی` را تست کنید.
16. برای لغو دستی، روی `لغو رزرو` بزنید و آزاد شدن صندلی‌ها را بررسی کنید.

## دمو برای کارمند کنترل بلیت

1. کد یکی از بلیت‌های صادرشده را کپی کنید.
2. در بخش `کنترل بلیت` آن را وارد کنید.
3. روی `بررسی بلیت` کلیک کنید.
4. نتیجه باید یکی از این حالت‌ها باشد:
   `معتبر`، `قبلاً استفاده شده`، `نامعتبر`

## دمو برای مدیر سینما و مدیر سیستم

1. داشبورد مدیر سینما را بارگذاری کنید.
2. گزارش فروش را باز کنید.
3. داشبورد مدیر سیستم را باز کنید.
4. لینک‌های RabbitMQ، Prometheus و Grafana را بررسی کنید.

## تست همزمانی

```bash
node tests/concurrency-demo.js
```

این اسکریپت یک سانس و یک صندلی آزاد را پیدا می‌کند، چند درخواست همزمان برای قفل همان صندلی می‌فرستد و باید دقیقاً یک قفل موفق داشته باشد.
