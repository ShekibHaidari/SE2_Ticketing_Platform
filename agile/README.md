# Agile Artifacts

This folder contains Scrum-oriented planning and tracking artifacts for the Software Engineering II course project.

Included artifacts:

- product backlog,
- user stories with acceptance criteria,
- sprint planning notes,
- sprint review summary,
- sprint retrospective notes,
- burndown sample data,
- sample Jira board export.

The content is intentionally academic and student-oriented, but it follows realistic Scrum structure and terminology.
