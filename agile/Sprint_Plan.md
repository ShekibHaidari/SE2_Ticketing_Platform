# Sprint Plan

## Team Roles

| Role | Responsibility |
| --- | --- |
| Product Owner | Maintains backlog priorities and accepts completed work |
| Scrum Master | Facilitates ceremonies and removes blockers |
| Backend Developer | Builds APIs, reservation, and payment logic |
| Frontend Developer | Builds user-facing booking screens |
| QA Engineer | Prepares and executes test plans |
| DevOps Engineer | Maintains infrastructure and deployment artifacts |
| System Analyst | Supports requirements, UML, and traceability |

## Sprint 1

### Objective

Establish the foundation of requirements, access control, event catalog, and core architecture.

### Planned Items

- Product vision and risk analysis
- Use case, class, activity, and component diagrams
- Auth API skeleton
- Event catalog API skeleton
- Initial database design

## Sprint 2

### Objective

Focus on concurrency-sensitive booking flows and payment integration design.

### Planned Items

- Waiting-room design
- Reservation lock workflow
- Reservation timeout and rollback design
- Payment callback flow
- Ticket issuance sequence modeling

## Sprint 3

### Objective

Prepare deployment, operations, testing, and final project packaging.

### Planned Items

- Docker environment
- Kubernetes manifests
- Terraform skeleton
- Testing and QA artifacts
- Final report and checklist review
